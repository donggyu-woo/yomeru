# yomeru

Chrome extension that shows Korean meanings of selected English and Japanese words.

## 설치 (개발자 모드)

1. [GitHub](https://github.com/donggyu-woo/yomeru) → **Code > Download ZIP** 이후 압축 해제
2. `chrome://extensions` 접속 → **개발자 모드** 활성화
3. **압축해제된 확장 프로그램을 로드** → `yomeru-main` 폴더 선택

*Note. 이미 열려 있는 탭은 새로고침 후 사용 가능*

## 사용법

툴바의 확장 프로그램 아이콘을 누르면 설정 창이 열립니다. 각각의 옵션은 아래와 같이 사용할 수 있습니다.

- **텍스트 선택 즉시 표시**: 텍스트를 드래그하면 바로 결과 창이 뜹니다.
- **텍스트 선택 시 「訳」 버튼 표시**: 텍스트를 드래그하면 「訳」 버튼이 표시되며, 버튼을 누르면 결과 창이 열립니다. (기본값)
- **우클릭 메뉴로만 표시**: 마우스 우클릭 → **"…" 번역** 으로만 엽니다.

*Note. 우클릭 메뉴는 모든 옵션에서 함께 사용 가능*

## 번역

Google 번역기를 통해 한국어로 번역합니다. 영어 단어는 품사별 뜻도 함께 표시합니다.

*Note. 선택한 텍스트는 번역을 위해 Google로 전송됩니다. 비공식 무료 엔드포인트를 사용하므로 요청이 많으면 일시적으로 제한될 수 있습니다.*

## 네이버 사전 바로가기

단어를 선택하면 결과 창에 「네이버 사전」 버튼이 표시되며, 선택 시에 네이버 사전(영한·일한) 검색 결과가 팝업 창으로 열립니다.
